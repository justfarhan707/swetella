# Sweetelle by Sana

Local, buildless bakery website. Open `index.html` or run `python -m http.server 4173 --bind 127.0.0.1` from `C:\Cake`.

The paper plane travels from Sana's kitchen to your house. The illustrated journey supports mobile and reduced motion. Below it, all 13 supplied images from `assets/img/` appear across the cake carousel, brownie feature, dessert tubs, full-size menu links and brand signoff.

## Image placement

- Carousel: s3, s6, s4, s5 and s1.
- Brownie feature: s2 and s10.
- Dessert tubs: s7, s8 and s9.
- Menus: jar_cake_menue and menue_tin_cake. Tap either to open the original full-size image.
- Brand signoff: Footer_image.

Photos use native lazy loading. The carousel supports touch, arrows and keyboard navigation. No dependencies or build step required. Illustrations remain SVG; replacing the supplied photos only requires keeping their filenames.

Colours: cream #FFF7ED, dusty rose #C98291, chocolate #3E2723, blush #F3DFE2, muted gold #C5A16D.
